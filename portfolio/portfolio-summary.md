# Project Operations & Billing Dashboard

## Overview
This project is an Excel-based dashboard designed to simulate real-world project operations and administrative workflows in a commercial construction or infrastructure environment. It centralizes project tracking, billing, documentation, inventory, and workflow stages into one structured system.

## Problem
Project teams often deal with scattered data across spreadsheets, emails, and tools, making it difficult to track project status, billing progress, documentation, and inventory in one place.

## Solution
I developed a multi-sheet Excel dashboard that integrates project setup, billing tracking, document control, inventory management, and workflow pipelines. The system uses formulas, dropdowns, and conditional formatting to automate tracking and highlight key risks.

## Tools Used
- Microsoft Excel
- Data validation (dropdowns)
- Conditional formatting
- Formulas (cost variance, aging, tracking)
- Charts and KPI visuals

## Key Features
- Project dashboard with KPI metrics
- Billing tracker with invoice aging and payment status
- Document control log (RFIs, submittals)
- Inventory tracker with low-stock alerts
- Workflow pipeline across project stages
- Automated calculations and reporting

## Business Value
This dashboard demonstrates how structured administrative systems can improve project visibility, reduce delays, enhance billing accuracy, and support coordination between teams.

## What I Learned
- Translating business workflows into structured systems
- Designing dashboards for operational clarity
- Using Excel as a lightweight project management tool
- Connecting administrative work to measurable outcomes
