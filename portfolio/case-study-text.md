# Project Operations & Billing Dashboard – Case Study

## Overview
This project is an Excel-based operations dashboard designed to simulate real-world project coordination, billing, inventory tracking, and workflow management in a construction or infrastructure environment.

The goal was to create a centralized system that improves visibility, organization, and efficiency across multiple project functions.

---

## Problem

Project teams often face:

- Disconnected data across spreadsheets, emails, and systems  
- Delayed billing and missed follow-ups  
- Poor visibility into project status and documentation  
- Inefficient tracking of materials and inventory  
- Lack of a structured workflow pipeline  

These issues can lead to project delays, cost overruns, and communication breakdowns.

---

## Solution

I designed a multi-sheet Excel dashboard that integrates key operational functions into one structured system:

- Project tracking  
- Billing and invoice monitoring  
- Document control (RFIs, submittals)  
- Inventory tracking  
- Workflow pipeline management  

The system uses formulas, dropdowns, and conditional formatting to automate tracking and improve visibility.

---

## System Design

The dashboard is divided into five main modules:

### 1. Project Dashboard
Provides a high-level view of project status, completion percentage, and budget vs. actual cost.

### 2. Billing Tracker
Tracks invoices, payments, change orders, and aging to ensure billing accuracy and follow-up.

### 3. Document Control
Maintains logs for RFIs and submittals, ensuring documentation is organized and up to date.

### 4. Inventory Tracker
Monitors materials, supply levels, and usage to prevent shortages and improve planning.

### 5. Workflow Pipeline
Tracks project stages from setup to closeout, improving coordination and visibility.
